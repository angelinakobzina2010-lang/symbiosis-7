# Симбиоз — станция «Симбиоз-7»

Камерный 3D-симулятор ухода за мутагенным растением для второго этапа НТО «Разработка игр».

## Игровой прототип

В проекте собран стартовый игровой цикл:

- Параметры среды: температура, влажность, CO₂ и минералы. Среда обновляется раз в 10 секунд; ночью изменение приостанавливается.
- Три фазы растения, заданные ассетами `PlantState`. Фаза проверяется при пробуждении игрока.
- Интерактивные предметы: лейка, удобрение и УФ-лампа.
- Сон длится 2 секунды, затем проходит проверка фазы, случайное событие станции и начинается следующий день.
- HUD показывает параметры среды, день и предмет в руке.

## Запуск

Откройте сцену `Assets/Scenes/SymbiosisPrototype.unity` в Unity 6.3 LTS (`6000.3.28f1`) и нажмите Play. Кликните по предмету, затем по растению, чтобы применить его. Кнопка «СПАТЬ · 2 СЕК.» завершает день.

Проверку прототипа можно запустить в редакторе Unity через меню **Symbiosis → Run Prototype Smoke Check**.

## Структура

- `Assets/Scenes` — сцены прототипа и исходная сцена шаблона.
- `Assets/Scripts` — системы среды, дней, роста растения, событий, взаимодействия и интерфейса.
- `Assets/Data/PlantStates` — данные трёх фаз растения.
- `Assets/Prefabs` — префабы растения и предметов.
- `Assets/Materials/Prototype` — материалы заглушек.
- `Packages/manifest.json` — зависимости Unity Package Manager.
- `ProjectSettings/ProjectVersion.txt` — версия Unity Editor.

## Модели

Для текущего прототипа используются примитивные формы Unity вместо финальных моделей и анимаций.
