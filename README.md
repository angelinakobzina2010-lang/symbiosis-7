# Симбиоз — станция «Симбиоз-7»

Камерный 3D-симулятор ухода за мутагенным растением. Проект для второго этапа НТО «Разработка игр».

## Концепция
После аварии экипаж исчез с орбитальной станции «Симбиоз-7». Растение стало единственным источником кислорода. Игрок просыпается день за днём, ухаживает за ним и решает, кем оно станет: объектом контроля, союзником или угрозой.

## Игровой цикл
1. Наблюдать за растением и состоянием станции.
2. Выбрать действие — например, свет, воду или минералы.
3. Увидеть, как меняются параметры среды и форма растения.
4. Лечь спать: наступает следующий день, срабатывает событие, растение реагирует на условия.
5. Решить, контролировать растение, сотрудничать с ним или рискнуть быть поглощённым.

У растения запланированы три фазы роста. Температура, влажность, CO₂ и минералы влияют на фазу; реакция проверяется при пробуждении. Возможны события станции, например поломка лампы, прорыв трубы или утечка минералов.

## Технологии
- Unity 6.3 LTS (`6000.3.28f1`)
- 3D, C#

## Структура проекта
- `Assets/Scenes` — сцены
- `Assets/Scripts` — C#-скрипты
- `Assets/Prefabs` — префабы растения и предметов
- `Assets/Art` — модели, текстуры и материалы
- `Assets/UI` — интерфейс и HUD
- `Assets/Audio` — музыка и звуковые эффекты
- `Packages/manifest.json` — зависимости Unity Package Manager
- `ProjectSettings/ProjectVersion.txt` — версия редактора Unity
